
# EuroLeague 2025/26

**Парсинг и разведочный анализ баскетбольной статистики на Python**

## О проекте

Проект посвящён сбору и анализу результатов матчей регулярного сезона Евролиги 2025/26.

Работа состоит из двух завершённых докладов:

1. **Web Scraping** — получение результатов матчей с сайта и сохранение в CSV.
2. **EDA (Exploratory Data Analysis)** — статистический анализ данных, проверка гипотез и построение графиков.

## Датасет

| Показатель | Значение |
|---|---|
| Сезон | 2025/26 |
| Команды | 20 |
| Матчи | 380 |
| Матчей на команду | 38 |

Для каждого матча сохранены:

- `date` — дата
- `home_team` — хозяева
- `away_team` — гости
- `home_points` — очки хозяев
- `away_points` — очки гостей

Датасет: `data/processed/matches.csv`

## Доклад №1 — Web Scraping

Реализован Python-парсер, который:

- Загружает HTML-страницы.
- Извлекает информацию о матчах.
- Обрабатывает полученные данные.
- Сохраняет результаты в CSV.
- Проверяет корректность собранного датасета.

**Библиотеки:** Requests, BeautifulSoup, Pandas.

Код: `scraping/fetch.py`

Подробный отчёт по Web Scraping: `docs/01_web_scraping.md`

## Доклад №2 — EDA

Проведён разведочный анализ 380 матчей Евролиги.

Основные этапы:

- Проверка качества данных.
- Расчёт среднего, медианы, дисперсии и стандартного отклонения.
- Анализ квартилей, IQR и выбросов.
- Исследование домашнего преимущества.
- Проверка статистических гипотез.
- Расчёт корреляции Пирсона.
- Анализ результативности по месяцам.
- Сравнение статистики команд.

Построено 6 графиков:

1. Распределение суммарных очков и KDE.
2. Boxplot очков хозяев и гостей.
3. Распределение разницы очков.
4. Корреляция между очками команд.
5. Динамика средней результативности по месяцам.
6. Количество побед команд.

**Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, SciPy.

Код: `eda/eda_analysis.py`

Подробный отчёт по EDA: `docs/02_eda.md`

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск EDA

```bash
python eda/eda_analysis.py
```

Программа рассчитывает статистические показатели, создаёт графики и обновляет блок результатов в Markdown-отчёте.
