# EuroLeague 2025/26

**Парсинг и анализ баскетбольной статистики на Python**

---

## О проекте

В этом проекте я буду собирать и анализировать статистику матчей Евролиги сезона 2025/26.

Проект состоит из двух частей:

1. **Web Scraping** — напишу парсер, который собирает результаты матчей с сайта и сохраняет их в CSV.
2. **EDA** — проанализирую полученные данные, построю графики и попробую найти интересные закономерности.

## Какие данные будем собирать?

| Показатель | Значение |
|---|---|
| Команды | 20 |
| Туры | 38 |
| Матчи | 380 |
| Сезон | 2025/26 |

Для каждого матча планирую получить дату, команды, счёт и победителя.

## Что будем использовать?

**Для парсинга:**
- Python
- Requests
- BeautifulSoup

**Для анализа:**
- Pandas
- NumPy
- Matplotlib

## Как всё будет работать?

Сайт → HTML → Python-парсер → CSV → Анализ данных
